Fair questions

Is this financial advice?

No. It's an educational tool. The model's test accuracy hovers around 50% — barely above coin-flip, which is normal for daily price data. Veriss tells you that on every result instead of hiding it.

Where does the data come from?

Prices from Yahoo Finance with automatic Twelve Data failover; company fundamentals from Yahoo with Finnhub failover; investor portfolios scraped from Dataroma. Everything is cached daily on disk.

Why doesn't it beat buy & hold?

Because almost nothing does with daily technical data — and tools that claim otherwise are selling you something. Veriss's value is a leak-free pipeline: chronological splits, next-day execution, costs included.

Can I run it myself?

Yes — it's MIT-licensed Python. Clone the repo, pip install -r requirements.txt, add two free API keys, and both the web and desktop apps run locally.
